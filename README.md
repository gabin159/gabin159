### 🚀 Sobre mí

Soy estudiante de 8° semestre de **Ingeniería de Sistemas** con conocimientos en desarrollo **Web Full Stack** y enfoque principal en **Backend** y un poco den **Frontend**. Me apasiona el desarrollo de aplicaciones web integrando APIs REST (Python, FastAPI, Java, Spring Boot) con bases de datos relacionales y no relacionales.

Cuento con bases sólidas en **infraestructura y redes (Cisco)**, diseño de arquitecturas web seguras y buenas prácticas de desarrollo. He trabajado en la construcción de módulos web, automatización de procesos y despliegue con contenedores Docker.

Actualmente busco mi **práctica empresarial** para aportar código de calidad, integrarme a un equipo de desarrollo y continuar fortaleciendo mis habilidades profesionales.
